# 🚁 台南無人機積水巡檢隊

3D 第一人稱無人機遊戲：模擬操作無人機，在台南市區中尋找人力難以發現的隱藏積水處（登革熱防治巡檢）。使用 Three.js + Vite 建置。

## 🎮 立即遊玩

**👉 https://swhunag65221-pixel.github.io/drone/**

用電腦瀏覽器（建議 Chrome）開啟即可，不需要安裝任何東西。

## 遊戲玩法

- ⏱️ 遊戲時間 **2 分鐘**，倒數計時。
- 以**第一人稱視角**操作無人機在城市中飛行，尋找隱藏的積水處。
- 用畫面中央的準星對準可疑地點，**點擊滑鼠左鍵**標記回報。
- 積水表面會反光閃爍，仔細觀察屋頂、空地與巷弄角落！
- 場景中也有**沒有積水的誘餌**（有蓋水塔、乾的容器、乾的廢棄物堆等），誤報會扣分。
- 開始前有**積水樣態圖鑑**：以實際 3D 模型逐項介紹每種積水的外觀與可能位置。
- 時間結束後結算分數並給予評價；全部找到可提前結束並獲得剩餘時間獎勵。
- 結束後可進入**複盤模式**：未找到的積水以紅色光柱＋類型標籤標示，自由飛行查看，按 Esc 返回結算。

### 計分

| 目標 | 分數 | 說明 |
|------|------|------|
| 空水塔積水 | +30 | 藏在屋頂上，要飛到上方才看得到水面 |
| 工地帆布積水 | +25 | 空地／工地上蓋著建材堆的帆布，中央凹陷處積水 |
| 廢棄物積水 | +20 | 空地上的廢棄物堆旁的積水 |
| 屋頂花園積水 | +20 | 花盆綠意間藏著的積水 |
| 屋簷雨水槽積水 | +15 | 落葉堵塞排水口造成的積水 |
| 積水容器 | +10 | 巷弄、中庭裡的水桶、水盆、輪胎 |
| 誤報 | −5 | 標記到沒有積水的地方 |

### 操作

| 按鍵 | 功能 |
|------|------|
| 滑鼠 | 控制視角方向 |
| ↑ / ↓ / ← / →（或 W / A / S / D） | 前後左右飛行 |
| 空白鍵 | 上升 |
| Shift | 下降 |
| 滑鼠左鍵 | 標記積水處 |
| Esc | 暫停 |

> 若使用中文輸入法時 WASD 沒反應（常見於 Windows 中文輸入法攔截字母鍵），請改用方向鍵，或將輸入法切換為英文再遊玩。

## 開發與執行

```bash
npm install      # 安裝依賴
npm run dev      # 啟動開發伺服器，瀏覽器開啟顯示的網址即可遊玩
npm run build    # 打包正式版到 dist/
npm run preview  # 預覽打包結果
```

## 專案結構

```
index.html        # 頁面與 HUD / 開始 / 暫停 / 結束畫面
src/style.css     # UI 樣式
src/main.js       # 遊戲主流程：計時、計分、點擊標記、主迴圈
src/world.js      # 程序化生成城市、積水目標與誘餌
src/drone.js      # 無人機第一人稱飛行控制與碰撞
```

每次重新開始遊戲，城市與積水位置都會重新隨機生成。
